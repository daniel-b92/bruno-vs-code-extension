Copies of the YAML grammars built into VS Code (1.141.0, `extensions/yaml/syntaxes/`), only used for tokenizing Yaml files in tests.
They originate from https://github.com/RedCMD/YAML-Syntax-Highlighter (MIT license, see [LICENSE.md](LICENSE.md); see the `version` field of each file for the exact commit).

When updating them, copy the files from `<VS Code installation>/resources/app/extensions/yaml/syntaxes/`.
